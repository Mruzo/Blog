# Email Templates

This folder contains HTML and plain-text templates for application emails.

## Conventions

- Keep each email available in both `.html` and `.txt` formats.
- Reuse `base_email.html` for shared layout and styling.
- Keep copy clear, short, and user-facing.
- Do not include secrets, raw tokens, server details, or internal troubleshooting notes in template docs.
- Test email changes locally before deployment.

Use the existing templates as the source of truth for naming and structure.
