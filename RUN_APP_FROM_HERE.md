# Run the app from this directory only

**Canonical project root:** this folder (the main vybz repo).  
**Do not** run the React app from Git worktrees (e.g. `jaq`). Open this folder in Cursor/IDE.

## React frontend

From this repo root:

```bash
cd vybzapp/frontend && npm start
```

Or:

```bash
./run-frontend.sh
```

Always use the frontend at `vybzapp/frontend` in this repository.
