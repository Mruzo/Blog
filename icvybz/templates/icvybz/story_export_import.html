How to Use Export/Import
Exporting Stories
  1. Select the story you want to export
  2. Choose whether to include file data and analytics
  3. Click "Export Story" to download the JSON file
  4. Save the file to transfer to another app
Importing Stories
  1. Select a JSON file exported from another app
  2. Choose whether to skip file data for faster import
  3. Click "Import Story" to add it to your stories
  4. View and manage your imported story
What Gets Exported/Imported:
  • Story details (title, description, settings)
  • All seasons and episodes
  • Character information and POVs
  • All dialogues with camera settings
  • Scene information and intersections
  • File data (images, 3D models) - optional
  • Analytics data (view counts) - optional
