Data workflow

  1. Add tickers in admin → Securities
  2. Star the ones you track → Watch list entries (or FMP catalog)
  3. Refresh EOD market close (1 FMP call / ticker) for real last trade-date prices
  4. Refresh quarterly fundamentals (3 FMP calls / ticker) for ratios, growth, and implied valuation price
  5. Optional: report filing dates (1 FMP call / ticker)
  6. Run screens — zero API calls; snapshots saved on each run
