# Justvybz - Immersive Storytelling Platform

Justvybz is an innovative platform for creating and experiencing immersive 3D comic stories with interactive dialogues, dynamic camera controls, and collaborative features.

## 🚀 Features

- **Immersive 3D Storytelling**: Create interactive 3D comic stories with dynamic camera controls
- **Collaboration Tools**: Work with other creators on shared narratives
- **Studio Management**: Build creative studios and invite collaborators
- **E-Commerce Integration**: Optional product sales functionality

## 📖 Documentation

Comprehensive documentation is available in the [`docs/`](./docs/) directory:

- **[Documentation Index](./docs/README.md)** - Complete documentation overview
- **[Process Flows](./docs/processes/)** - Technical implementation details
- **[Reviews & Analysis](./docs/reviews/)** - Feature reviews and analysis
- **[Testing Documentation](./docs/testing/)** - Test strategies and plans
- **[User Guides](./docs/guides/)** - User-facing guides and tutorials

## 🛠️ Technology Stack

- **Backend**: Django 3.2, Django REST Framework
- **Frontend**: React, TypeScript
- **Database**: PostgreSQL (production), SQLite (development)
- **Storage**: AWS S3 (production)
- **Payment**: Stripe
- **Shipping**: Canada Post API

## 🔒 Security & Compliance

This platform implements industry-standard security practices:
- **PCI DSS**: Compliant via Stripe hosted checkout
- **OWASP Top 10**: Protection against common vulnerabilities
- **GDPR**: Data export and deletion capabilities
- **NIST Framework**: Security logging and monitoring

See [Security Implementation](./docs/implementation/TECHNICAL_IMPROVEMENTS_IMPLEMENTED.md) for details.

## 📁 Project Structure

```
vybzapp/
├── frontend/          # React frontend application
├── snmov/            # E-commerce app
├── icvybz/           # Immersive comics app
├── templates/        # Django templates
└── docs/             # Project documentation
```

## 🚦 Getting Started

### Prerequisites
- Python 3.7+
- Node.js 14+
- PostgreSQL (for production)

### Installation
1. Clone the repository
2. Set up virtual environment: `python -m venv vybzenv`
3. Install dependencies: `pip install -r requirements.txt`
4. Configure settings in `snm/settings/local.py`
5. Run migrations: `python manage.py migrate`
6. Start development server: `python manage.py runserver`

For detailed setup instructions, see the [Registration Process](./docs/processes/REGISTRATION_PROCESS.md) documentation.
